# Optional metadata probe in an owned AudioEditor module

Use only if the resolver's public generic loaders do not expose enough graph/container metadata. This continuation is source-only and uncompiled. No stage, native session, lease, production file or manual candidate was changed by this lane.

Source module copy root remains signal-probe/scripts/WorkbenchGame/GEP033, now four files. New class: GEP033_InspectAudioPortsPlugin. Parent native launch arguments: -wbModule=AudioEditor -plugin=GEP033_InspectAudioPortsPlugin. Existing success marker, 9 observations and evidence protocol remain unchanged. Native launcher/close belongs to root. Do not run this against an existing human editor.

The child plugin uses the module already opened by the parent launcher, and calls supported AudioEditor.SetOpenedResource/GetNumContainers/GetContainer for the current stock left/right wheel ACPs and engine. It calls no Save, preview/Play, ExecuteAction, Workbench.Exit, OpenModule, process, input or lease operation. Opening a resource changes only this new owned editor's resource view; do not describe that as a zero-state-change probe. No manual AudioEditor UI is required to request the metadata. Actual runtime loading behavior remains unqualified.

The parent resolver now emits bounded signal node resource references plus input/output port IDs, bank parameter-input connection endpoints and raw present/update flag tables. It does not read/serialize SIG algorithms or audio waveform payloads, or inspect any WCS/SpaceCore resource. Truncation is explicit beyond 64 signal nodes, 64 banks, 16 bank inputs or 16 links. Names/ports are metadata, not proof of their units or active signal context.

The useful result would be: an exact canonical current stock wheel Sound parent config; a native enum label/value mapping for VEH_Tires and the existing sound's output state/port; and the stock SIG resource and its volume/pitch output endpoints. If exposed, a new original scratch ACP can reference that stock SIG/config and the exact stock Slow WAV without redistributing their implementation. Preserve the LAV engine and cannon graphs. Do not infer a VEH_Tires numeric port from enum order or an unrelated engine route.

Stock wheel graphs may rely on a per-wheel sound context that is absent in a generic hull SoundEvent. A reference-based graph must first prove its signal values in the exact intended component/slot. Container metadata does not prove that custom event context. If generic loaders and the AudioEditor module both expose no matching AudioClass, preserve that exact limit; do not dump undocumented payloads or relabel an empty result as a valid graph.

Primary idle mute may instead use an owned event's termination below a stable motion threshold, with starts only on a stable movement transition and no per-frame/speed-change restart. That avoids treating -60dB attenuation as exact silence. Keep this separate from the initial one-attempt lifecycle probe, and test stop/start hysteresis, one handle, fade completion, culling return and delete cleanup before admission. Dynamic speed-related volume/pitch still needs a verified native control path; movement on/off alone does not complete GEP033.

Current shared parent protocol uses fixed `$profile:GEP033-RESOLVER.json`, no System.GetCLIParam/GetCmdLine and no custom output CLI argument. Each native run must have a fresh unique profile, and collisions are refused. A new authorization prompt remains pending until authorized, rather than prompting an alternative protected-call attempt.
